# 📚 Revisão P1 – Aprendizagem de Máquina
Repositório criado para reunir os conteúdos e atividades de **revisão para a P1 da disciplina de Aprendizagem de Máquina**.

## 🎯 Objetivo

Este projeto tem como objetivo revisar os principais conceitos estudados em aula, com foco em **Aprendizado Supervisionado, Aprendizado Não Supervisionado e Regressão Linear**.

## 📖 Conteúdos

* Aprendizado Supervisionado
* Aprendizado Não Supervisionado
* Dados rotulados e não rotulados
* Regressão Linear
* Equação `y = mx + b`
* Treinamento e validação de modelos
* Generalização
* Viés Indutivo
* Aprendizado Preditivo e Descritivo
* K-Means
* Interpretação de resultados
* Aplicação da Regressão Linear em situações reais

## 📝 Revisão

A revisão contém questões divididas em diferentes categorias:

### Parte A – Questões Objetivas

Questões sobre os principais conceitos de aprendizagem de máquina e regressão linear.

### Parte B – Verdadeiro ou Falso

Afirmações para revisar conceitos fundamentais.

### Parte C – Questões Discursivas

Questões sobre:

* Diferenças entre aprendizado supervisionado e não supervisionado;
* Etapas do treinamento de um modelo;
* Generalização;
* Viés indutivo.

### Parte D – Interpretação e Aplicação

Exercícios utilizando regressão linear para analisar a relação entre **temperatura e vendas de sorvete**.

### Parte E – Análise de Cenários

Classificação de problemas como **preditivos ou descritivos**, além da identificação de problemas de classificação e regressão.

## 🧠 Conceitos principais

| Conceito           | Descrição                                                  |
| ------------------ | ---------------------------------------------------------- |
| Supervisionado     | Utiliza dados com entradas e respostas conhecidas          |
| Não supervisionado | Busca padrões em dados sem respostas previamente definidas |
| Regressão          | Prevê valores numéricos                                    |
| Classificação      | Prevê categorias                                           |
| K-Means            | Algoritmo de agrupamento não supervisionado                |
| Regressão Linear   | Modelo utilizado para prever valores numéricos             |
| Generalização      | Capacidade de funcionar com dados novos                    |
